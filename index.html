    Using second functions

    For variables, press 9 → STO → ALPHA → A to store 9 in A. Repeat with B. ALPHA → A → ALPHA → B → = displays AB and calculates their product.

    SHIFT selects a yellow second function; ALPHA selects a red letter. The LCD indicates D for degrees and R for radians.

    Example: 9 → x² → = displays 81. Select DEG or RAD using the round button at top right.
